# 악보 암기

내 MusicXML 악보를 올려서 마디 퍼즐, 악절 순서, 음표 빈칸, 악상 퀴즈 등으로 외우는 연습 앱입니다.
서버 없이 브라우저에서만 동작하고, 올린 악보와 진도는 그 기기의 브라우저에만 저장됩니다.

## 쓰는 법

1. 악보 편집기에서 MusicXML(`.musicxml`, `.xml`, `.mxl`)로 내보낸 파일을 보관함에 올립니다. 화면 아무 곳에나 끌어다 놓아도 됩니다.
2. 연습 구간(곡 전체, 또는 일부 마디)을 고릅니다.
3. 유형을 골라 풀거나, "오늘의 복습"으로 약한 마디 위주 10문제를 섞어 풉니다.

PDF·사진·MIDI·MuseScore 원본(`.mscz`)은 읽을 수 없습니다.

## 연습 유형

| 묶음 | 유형 | 내용 |
| --- | --- | --- |
| 순서 | 마디 퍼즐 | 뒤섞인 마디를 끌어서 서로 자리를 바꿔 순서 맞추기 |
| | 악절 순서 | 4마디 악절의 순서 맞추기 |
| | 다음 마디 고르기 | 이 마디 다음에 오는 마디 고르기 |
| 세부 | 음표 빈칸 | 가려진 음을 건반으로 답하기. 화음이면 모든 음을 고름 |
| | 악상 고르기 | 가려진 셈여림·헤어핀·빠르기말·아티큘레이션을 객관식으로 |
| | 비슷한 마디 구별 | 닮은 두 마디 가려내기 |
| | 짝이 되는 손 고르기 | 한 손 악보를 보고 맞는 반대 손을 4지선다로 (피아노 악보) |
| 귀와 위치 | 듣고 찾기 | 소리와 같은 악보 고르기 |
| | 위치 맞추기 | 이 마디가 곡의 어디쯤인지 |
| 떠올리기 | 한 손 가리기 | 가린 손을 떠올리고 확인 (피아노 악보) |
| | 점점 지우기 | 음표를 조금씩 지우며 암기 |
| 분석 | 헷갈리는 구간 지도 | 비슷하지만 다른 마디 쌍을 나란히 비교 |

그 밖에 재생(속도 조절, 손별 소리 끄기), 한 손 가리기·지우기 보기, 마디별 숙련도 색, 간격 복습(틀린 마디는 곧 다시, 맞힌 마디는 점점 늦게), 진도 화면이 있습니다.

## 개발

정적 파일뿐이라 빌드가 없습니다. 캐시를 끈 개발 서버를 씁니다.

```bash
python tools/serve.py 8766
```

`http://127.0.0.1:8766`을 엽니다.

- `js/score.js` MusicXML 해석, 구간·한 손 추출, `.mxl` 압축 해제
- `js/engraver.js` Verovio 래퍼
- `js/audio.js` 오실레이터 재생
- `js/store.js` 진도(localStorage), 올린 악보(IndexedDB)
- `js/modes/` 연습 유형별 화면
- `tools/clean_score.py` 색 표시가 들어간 MusicXML에서 색 속성만 지우는 스크립트

## 예제 악보

- `samples/little-waltz.musicxml`은 이 프로젝트용으로 새로 쓴 16마디 연습곡이라 저장소에 포함합니다. `python tools/make_sample.py`로 다시 만들 수 있습니다.
- 출처와 이용 조건을 확인할 수 없는 전사본은 저장소에 넣지 않습니다. `data/`에 `rachmaninoff-op39-no6.musicxml`, `bartok-allegro-barbaro.musicxml`을 두면 로컬에서만 "예제"로 보입니다(`.gitignore`로 제외됨).

`assets/demo-*.gif`는 위 샘플 곡으로 실제 앱 화면을 캡처해 만든 메인 화면의 활용 장면입니다.

## 배포

GitHub Pages(브랜치 루트)로 배포합니다. 빌드 단계가 없습니다.

호스팅이 JS·CSS를 4시간 캐시하므로, 배포 직전에 `python tools/stamp.py`로 `index.html`의 `?v=` 값을 갱신한 뒤 커밋합니다.

## 라이선스와 출처

악보 표시는 [Verovio](https://www.verovio.org/) 4.3.1(LGPL-3.0-or-later)을 `vendor/verovio/`에 그대로 포함합니다.

## 사이트 메타데이터·게시자 통합

`node tools/site_metadata.mjs`로 canonical, 4대 태그와 GTM noscript, sitemap.xml, robots.txt, ads.txt를 재생성합니다. `node --test tests/publisher.test.mjs`로 로컬 요청 차단과 입력값 제외를 검사합니다.
